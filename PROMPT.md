# Shu landing page uchun prompt (O'zbekcha)

Menga HTML, CSS va JavaScript'da juda kreativ, zamonaviy shaxsiy portfolio landing page yarat.

**Men haqimda:** ismim Sevinchxon, men dasturchiman. Profil rasmim: images/profile.png

**Fayl tuzilmasi (alohida papkalar):**
- index.html
- css/style.css
- js/main.js (mantiq: tema, til, animatsiya)
- js/i18n.js (UZ va EN tarjimalari)
- images/ (profil rasm, favicon, loyiha rasmlari)

**Talablar:**
1. Ikki rejim: dark va light. Tugma bilan almashadi, tanlov localStorage'da saqlanadi, birinchi marta kirganda tizim rejimiga qarab tanlanadi. Barcha ranglar CSS o'zgaruvchilarida bo'lsin.
2. Ikki til: UZ va EN. Tugma bilan almashadi, tanlov saqlanadi. Barcha matnlar data-i18n atributlari orqali i18n.js'dan olinsin.
3. Bo'limlar: navbar, hero (ism, kasb, tugmalar, profil rasm), skills marquee, men haqimda, ko'nikmalar, loyihalar, yo'lim (timeline), aloqa formasi, footer.
4. Dizayn: shablon ko'rinishidan qoching. Qizg'ish-pushti va binafsha palitra, Syne (sarlavha) + DM Sans (matn) shriftlari. Profil rasm arka shaklida, yonida kod yozilayotgan (typing) "sevinchxon.js" kartasi.
5. Animatsiya: kam, lekin esda qoladigan (hero'da bir martalik paydo bo'lish, kod yozilishi, rasm tilt effekti). prefers-reduced-motion ni hurmat qil.
6. To'liq responsive (mobil menyu bilan), klaviatura fokusi ko'rinsin, semantik HTML, alt matnlar.
7. Tashqi kutubxonalarsiz (faqat Google Fonts).
8. Kodga o'zbekcha izohlar yoz, men oson tahrirlay olishim kerak.
